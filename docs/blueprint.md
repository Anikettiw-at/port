# **App Name**: Web Weaver Portfolio

## Core Features:

- 3D Model Integration: Interactive 3D model of your avatar or logo that rotates on the landing page.
- Project Gallery: Showcase your projects with a filterable gallery using the skills you mentioned (HTML, CSS, TypeScript, JavaScript, TailwindCSS, Python).
- Resume Download: Prominent resume download link.

## Style Guidelines:

- Primary color: Dark gray (#333) for a professional base.
- Secondary color: Light gray (#f0f0f0) for contrast and readability.
- Accent: Teal (#008080) for interactive elements and highlights.
- Responsive design for seamless viewing across devices.
- Use a grid-based layout to present your work in a clean and organized manner.
- Subtle animations on hover for interactive elements to enhance user experience.
- Use a set of consistent icons to represent different sections of your portfolio.
